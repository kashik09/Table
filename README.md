# Weather Table Project

This is a simple project I made for my coding bootcamp at Moringa. I incorporated the use of **HTML** and **CSS** to create the table. It lists weather conditions for each day of the week.

## About the Project

The project has:
- A **title** and **two short paragraphs** explaining what the table is about.
- A **table** that shows:
  - Days of the week (Monday to Friday).
  - Weather conditions (Sunny, Windy, Rainy, Cloudy).
  - If the weather condition happens on a certain day, the table says so.

### Table Example

|        | Sunny   | Windy  | Rainy  | Cloudy     |
|--------|---------|--------|--------|------------|
| Monday |         | Yes    |        | Partially  |
| Tuesday| No      |        | Yes    |            |
| Wednesday|       | Yes    |        |            |
| Thursday|        |        |        | Partially  |
| Friday |         | Yes    |        |            |

At the bottom of the table, there’s a caption: **"A table showing weather data for the week."**
